公地引擎 · 实体关系图 (ER Diagram)

11 张表 · 6 个领域数据库 · 逻辑外键（无物理约束）· 支持平滑分库

分库策略

  • • 6 个领域数据库，按模块边界垂直拆分
  • • 无物理外键，逻辑 ID 引用，零迁移阻力
  • • 各库独立主从配比，按负载定制

分表策略

  • • member: id % 64 (64分片)
  • • vote: proposal_id % 128 (128分片)
  • • payment_ledger_event: hash(tx) % 256
  • • 预留 2 的幂次扩容空间

特殊处理

  • • worker_location → Redis Geo
  • • payment_ledger_event → 冷热分离
  • • ShardingSphere-JDBC 分片中间件
  • • SnowflakeId 全局唯一 ID
